# Orman Parkur Kahramanı

Bu proje, GitHub Pages veya doğrudan tarayıcı üzerinden çalıştırılabilen, tek sayfalık bir 2D parkur/atıcı oyunudur.

Özellikler:
- Sol / sağ hareket
- Zıplama
- Silah ve ateş etme
- Kaplumbağa düşmanları
- Ormanlık arka plan ve parkur platformları
- Hedef bayrak, kazanma ve yeniden başlatma

Çalıştırma:
1. Bu klasördeki `index.html` dosyasını doğrudan tarayıcıda açın.
2. Veya GitHub Pages kullanacaksanız dosyaları repo köküne koyup statik site olarak yayınlayın.

Kontroller:
- A / D veya sol-sağ oklar: hareket
- W / ↑ / Boşluk: zıplama
- F / J / K: ateş etme
- R: oyun bittiğinde yeniden başlatma

Not: Bu proje sade, bağımsız bir HTML5 Canvas oyunudur; ek paket kurulumu gerektirmez.
